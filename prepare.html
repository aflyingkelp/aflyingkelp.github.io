Touhou 10 · Mountain of Faith

Bring your own game.

Turn the th10.dat file from your copy of Mountain of Faith into a browser import package. Your game file stays on this device.

Find this file in your Touhou 10 installation folder.

Download import ZIP
  1. Download the import ZIP created above.
  2. Open the launcher, choose Import, and select that ZIP.
  3. Set Music to Off, then start Mountain of Faith.

This package includes the game data and GNU Unifont. Background music is separate; existing full EAGLER TOUHOU packages with music can also be imported in the launcher.
