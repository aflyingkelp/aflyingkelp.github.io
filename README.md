# Self-hosted Touhou library

All active pages, launcher code, runtime code, fonts, and tools are served from this GitHub Pages origin. External game-server embeds and direct-open fallbacks have been removed. A same-origin Content Security Policy blocks external resource connections.

Touhou 10 browser runtime is installed. Original game data is absent. Other listed titles do not yet have installed runtimes or game assets. The library displays installation status rather than advertising playable games.

Use self-hosted.html for the current library. The local import launcher is en.html?game=th10; prepare.html makes a local package from a player’s own th10.dat. No original game data is published.
