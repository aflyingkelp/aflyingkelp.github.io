# Touhou browser library

Live: https://aflyingkelp.github.io/index.html

The site offers the online host's available browser builds from Touhou 6 onward: 6, 7, 7.5, 8, 9, 10, 11, 12, 13, 15, 17, 19 and 20. Preview builds are labeled. TH13, TH17 and TH19 are temporarily unavailable because the upstream online server has a catalog error; their cards and picker entries are disabled. The other ten entries use the alternate test.touhou.vip host. Touhou 14, 16 and 18 and other spin-offs are not published by this host.

Choose a game, then click **Start game** inside the player. Local game-file import is unnecessary in online mode. Resources are provided by the external EAGLER TOUHOU service at touhouonline.com. Each player offers **Open directly** if embedded browser storage or fullscreen fails.

The game picker, fullscreen control, reload control and return-to-library link are available above the player. Click the game canvas before using the keyboard. Arrow keys move, Z confirms/shoots, X bombs/cancels, Shift focuses, and Escape pauses in the main STG games.

The original Touhou 10 local-import launcher remains at en.html?game=th10; prepare.html creates a local package from a player's own th10.dat. This repository does not distribute original game data or music.

GitHub Pages publishes main from the repository root. .nojekyll preserves static files; .gitattributes preserves exact hashed runtime bytes. Source and licenses: SOURCE.md, LICENSE, THIRD_PARTY.md, ASSETS.md and licenses/.
