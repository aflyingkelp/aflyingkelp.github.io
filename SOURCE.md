# Source and attribution

Launcher and browser runtime source: https://github.com/Ritosa2333/eagler-touhou

The files included in this repository are served locally. No upstream game website is embedded or contacted to supply gameplay. Upstream URLs in license and source documentation are attribution only.

The local TH10 runtime is based on 3.5.1-sdl3. Runtime HTML has a same-origin Content Security Policy; corresponding generation identifiers and file hashes have been regenerated. Local wrapper and installation-status pages are included in this repository.

Original game data and music are absent. GNU Unifont 16.0.04 is supplied under SIL OFL 1.1; see licenses/OFL-Unifont.txt.
